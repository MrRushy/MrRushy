## Featured Projects

### AttendEase Campus Companion
**Kotlin | Android Studio | Firebase/Firestore | Google Maps SDK | OpenStreetMap | Python**

AttendEase is a team-based senior project designed to improve campus life through scheduling, attendance tracking, social features, and campus navigation.

My main contribution was the interactive campus map subsystem, including searchable building markers, class-location support, route preview functionality, and graph-based navigation using OpenStreetMap-derived campus paths. I also implemented shortest-route logic using Dijkstra’s algorithm over custom node and edge structures.

[View Repository](https://github.com/MrRushy/AttendEase-SeniorProject)

### Online Store Database Application
**Java | Swing | MySQL | SQL | IntelliJ IDEA**

A solo database-driven desktop application that simulates an online store with separate customer, employee, and admin workflows.

The application includes item browsing, shopping cart management, order placement, account updates, order cancellation, inventory management, account administration, and order status control. I designed the normalized MySQL schema and connected the Java GUI to the database using SQL queries.
